Performed EDA on titanic dataset that includes removing unnecessary columns and duplicate records and handling missing values. Converted all categorical variables into numbers as machine can't understand categorical data. Splitted the prepared data into training and testing datasets (80% goes into training whereas 20% goes into testing). Afterwards, I implemented a decision tree classification algorithm by passing the unseen data and got 80% accuracy. Found the best split attribute that has the highest information gain and represented the same using a tree diagram.
